# 미소년 CLASS
AI·컴퓨터·스마트폰 수강생을 위한 정적 교육 홈페이지.
주소: https://bonitajo.github.io/home/

## 링크 변경
GitHub에서 config.js를 열고 연필(Edit) 버튼을 누릅니다. links 안의 주소만 바꾸고 Commit changes로 저장합니다. Pages 배포 후 홈페이지를 새로고침합니다.
- registration: 첫 수업 구글 폼
- materials: 구글 드라이브 공유 폴더
- googleBlog: 구글 블로그
- naverBlog: 네이버 블로그
- youtube: 유튜브 채널
빈 문자열("")은 준비 중입니다. https:// 주소만 연결됩니다. 비밀번호나 비밀키를 절대 넣지 마세요.

## 구글 폼 준비
이름이나 홈페이지 회원가입 항목 없이 지메일 주소와 배우고 싶은 내용만 질문하세요.
공개하기 전에 실제 운영에 맞는 수집 목적, 수집 항목, 보유 기간, 문의 방법과 동의 안내를 폼에 작성하세요. 예: 수업 자료 및 강좌 안내를 위한 지메일 주소 수집. 보유 기간 등 미정인 내용은 운영자가 결정해야 합니다.
폼과 드라이브는 수강생의 접근 권한으로 열리는지 별도로 점검하세요. 공유할 자료만 폴더에 넣으세요.

## 운영
HTML/CSS/JavaScript만 사용하며 빌드와 유료 서비스가 필요 없습니다.
GitHub Pages: main 브랜치 / (root), Deploy from a branch.
모든 파일 경로는 상대 경로라 /home/ 아래에서도 동작합니다.
외부 링크는 새 탭으로 열리며 noopener noreferrer를 적용합니다.
분석 도구, 쿠키, 로컬 저장소, 개인정보 입력 폼을 사용하지 않습니다.
외부 서비스의 개인정보 처리는 각 서비스에 따릅니다.

## 확장
config.js는 설정, app.js는 링크 렌더링, styles.css는 디자인, index.html은 화면 구조를 담당합니다.
관리자 인증·데이터베이스·공지사항·기관별 강의실·작품 갤러리는 미구현입니다.
추후 Firebase Authentication 등과 권한 검증이 있는 서버 저장소를 연결하고, 설정을 읽는 부분을 교체하는 방향으로 확장하세요. 클라이언트 비밀번호 방식은 사용하지 않습니다.
